### 1.1 Text-to-Speech (TTS): Kokoro-82M

**Why Kokoro?**

Kokoro is an open-source TTS model that transforms text into natural-sounding speech with remarkable efficiency. Despite its compact size of 82 million parameters, it delivers high-quality voice synthesis comparable to models ten times larger.

**Key Features:**
- **54 voices** across multiple languages (English, French, Japanese, Chinese, Hindi)
- **Near real-time generation** on modern hardware
- **Natural prosody** that sounds human, not robotic
- **Voice cloning** via reference audio

**Available Voices:**

| Category | Voice IDs | Use Case |
|----------|-----------|----------|
| **American Female** | `af_bella`, `af_sarah`, `af_sky`, `af_nicole` | Child-friendly characters |
| **American Male** | `am_adam`, `am_michael`, `am_liam`, `am_eric` | Teacher/guide voices |
| **British Female** | `bf_emma`, `bf_alice`, `bf_isabella` | Formal narration |
| **British Male** | `bm_george`, `bm_lewis`, `bm_daniel` | Authority figures |
| **French** | `ff_siwis` | Français content |

**Installation:**
```bash

git clone https://github.com/hexgrad/kokoro.git
cd kokoro

# Install dependencies
pip install kokoro

# Download models (~340MB)
python -c "from kokoro import KPipeline; KPipeline(lang_code='a')"
```

**Integration with Platform:**
```python
# server/services/kokoro_tts.py
from kokoro import KPipeline
import io
import soundfile as sf

class KokoroTTSService:
    def __init__(self):
        self.pipelines = {
            'en': KPipeline(lang_code='a'),  # American English
            'fr': KPipeline(lang_code='f'),  # French
        }
        self.default_voices = {
            'en': 'af_bella',
            'fr': 'ff_siwis',
        }
    
    async def synthesize(
        self,
        text: str,
        language: str = 'en',
        voice: str = None,
        speed: float = 1.0
    ) -> bytes:
        """Generate natural-sounding speech."""
        pipeline = self.pipelines.get(language, self.pipelines['en'])
        voice = voice or self.default_voices.get(language, 'af_bella')
        
        # Generate audio
        generator = pipeline(text, voice=voice, speed=speed)
        
        # Collect audio chunks
        audio_chunks = []
        for _, _, audio in generator:
            audio_chunks.append(audio)
        
        # Concatenate and convert to bytes
        import numpy as np
        full_audio = np.concatenate(audio_chunks)
        
        buffer = io.BytesIO()
        sf.write(buffer, full_audio, 24000, format='WAV')
        buffer.seek(0)
        
        return buffer.read()
```

### 1.2 Speech-to-Text (STT): Faster-Whisper

**Why Faster-Whisper?**

Faster-Whisper is a reimplementation of OpenAI's Whisper using CTranslate2. It runs up to **4× faster** than original Whisper, uses less RAM, and works seamlessly with Python.

**Key Features:**
- **99 languages** supported
- **4× faster** than original Whisper
- **Lower memory** usage
- **GPU acceleration** available
- **100% local** - no data leaves the server

**Model Sizes:**

| Model | Parameters | Use Case | Latency |
|-------|------------|----------|---------|
| `tiny` | 39M | Real-time | Lowest |
| `base` | 74M | General | Low |
| `small` | 244M | High accuracy | Medium |
| `medium` | 769M | Professional | Higher |
| `large` | 1550M | Best accuracy | Highest |

**Installation:**

```python
# server/services/faster_whisper_stt.py
from faster_whisper import WhisperModel

class FasterWhisperSTTService:
    def __init__(self):
        # Load models for different languages
        self.models = {
            'base': WhisperModel("base", device="cuda", compute_type="float16"),
            'small': WhisperModel("small", device="cuda", compute_type="float16"),
        }
    
    async def transcribe(
        self,
        audio_bytes: bytes,
        language: str = None,
        model_size: str = 'base'
    ) -> dict:
        """Transcribe audio to text with language detection."""
        # Save to temporary file
        import tempfile
        with tempfile.NamedTemporaryFile(suffix='.wav', delete=False) as f:
            f.write(audio_bytes)
            audio_path = f.name
        
        # Transcribe
        model = self.models.get(model_size, self.models['base'])
        segments, info = model.transcribe(
            audio_path,
            language=language,  # None for auto-detect
            beam_size=5,
            word_timestamps=True
        )
        
        # Collect results
        transcription = " ".join([segment.text for segment in segments])
        
        return {
            "text": transcription.strip(),
            "language": info.language,
            "language_probability": info.language_probability,
            "duration": info.duration
        }
```

### 1.3 Speech-to-Speech (STS): Chroma-1.0 or MOSS-Speech

#### Option A: Chroma-1.0 (Recommended for Voice Cloning)

Chroma-1.0 is an open-source end-to-end speech conversation model developed by FlashLabs, focusing on real-time speech generation, customized voice cloning, and end-to-end architecture.

**Key Features:**
- **Real-time speech generation** with low latency
- **Customized voice cloning** capability
- **End-to-end architecture** - complete speech-to-speech workflow
- **Speech reasoning** - understands and processes speech content

**Architecture:**
- **Reasoner:** Based on Qwen2.5-Omni-3B
- **Backbone:** Based on Llama3 (16 layers, 2048 hidden size)
- **Codec:** Mimi (24kHz sampling rate)

#### Option B: MOSS-Speech (True Speech-to-Speech Without Text Guidance)

MOSS-Speech introduces true end-to-end speech interaction. Unlike cascaded pipelines or text-guided models, it directly generates speech without first producing text. This overcomes the limitation of generated speech being constrained by a text bottleneck, enabling more natural and efficient speech-to-speech dialogue.

**Key Features:**
- **True Speech-to-Speech Modeling:** No text guidance required
- **Layer-Splitting Architecture:** Integrates modality-specific layers on top of pretrained text LLM backbones
- **Frozen Pre-Training Strategy:** Preserves LLM reasoning while enhancing speech understanding and generation
- **Expressive & Efficient:** Maintains paralinguistic cues often lost in cascaded pipelines, such as tone, emotion, and prosody

**Installation:**
```bash
# Clone repository
git clone https://github.com/OpenMOSS/MOSS-Speech
cd MOSS-Speech

# Install dependencies
pip install -r requirements.txt
git submodule update --init --recursive

# Launch web demo
python3 gradio_demo.py
```

**Python API:**
```python
import os
from dataclasses import astuple
import torch
import torchaudio
from transformers import AutoModel, AutoProcessor, GenerationConfig

model_path = "fnlp/MOSS-Speech"
codec_path = "fnlp/MOSS-Speech-Codec"

processor = AutoProcessor.from_pretrained(
    model_path, 
    codec_path=codec_path, 
    device="cuda", 
    trust_remote_code=True
)

model = AutoModel.from_pretrained(
    model_path, 
    trust_remote_code=True, 
    device_map="cuda"
).eval()

messages = [
    {"role": "system", "content": "You are a helpful voice assistant for Cameroonian children."},
    {"role": "user", "content": "À bwɛ̀! Nà wù dà?"}
]

encoded_inputs = processor(messages, "audio")

with torch.inference_mode():
    token_ids = model.generate(
        input_ids=encoded_inputs["input_ids"].to("cuda"),
        attention_mask=encoded_inputs["attention_mask"].to("cuda"),
    )

results = processor.decode(token_ids, "audio")
audio, text, sample_rate = astuple(results[0])

# Save audio
torchaudio.save("response.wav", audio, sample_rate)
```

### 1.4 Complete Pipeline: HuggingFace Speech-to-Speech

For a **production-ready, modular solution**, use the HuggingFace `speech-to-speech` codebase. The `speech-to-speech` codebase is a modular framework for building local voice agents using open-source models. Its primary goal is to implement a low-latency, cascaded speech-to-speech pipeline.

**Architecture Components:**
- **VAD (Voice Activity Detection):** Silero VAD v5
- **STT (Speech-to-Text):** Whisper, Parakeet TDT, Faster-Whisper
- **LLM (Language Model):** Hugging Face Transformers, MLX-LM, any OpenAI-compatible API
- **TTS (Text-to-Speech):** Qwen3-TTS, Kokoro, Pocket TTS, ChatTTS

### 2.3 Unified Voice Service

```python
# server/services/unified_voice.py
from typing import Optional
import numpy as np

class UnifiedVoiceService:
    """Complete voice pipeline: STT → LLM → TTS with STS option."""
    
    def __init__(self):
        # Initialize STT
        from faster_whisper import WhisperModel
        self.stt_models = {
            "base": WhisperModel("base", device="cuda", compute_type="float16"),
            "small": WhisperModel("small", device="cuda", compute_type="float16"),
        }
        
        # Initialize TTS
        from kokoro import KPipeline
        self.tts_pipelines = {
            "en": KPipeline(lang_code='a'),
            "fr": KPipeline(lang_code='f'),
        }
        
        # Initialize STS (Chroma)
        self.chroma_url = "http://localhost:8000/v1/chat/completions"
    
    async def speech_to_text(
        self,
        audio_bytes: bytes,
        language: Optional[str] = None,
        model_size: str = "base"
    ) -> dict:
        """Convert speech to text."""
        import tempfile
        with tempfile.NamedTemporaryFile(suffix='.wav', delete=False) as f:
            f.write(audio_bytes)
            audio_path = f.name
        
        model = self.stt_models.get(model_size, self.stt_models["base"])
        segments, info = model.transcribe(
            audio_path,
            language=language,
            beam_size=5,
            word_timestamps=True
        )
        
        transcription = " ".join([seg.text for seg in segments])
        
        return {
            "text": transcription.strip(),
            "language": info.language,
            "confidence": info.language_probability,
        }
    
    async def text_to_speech(
        self,
        text: str,
        language: str = "en",
        voice: Optional[str] = None,
        speed: float = 1.0
    ) -> bytes:
        """Convert text to natural speech."""
        pipeline = self.tts_pipelines.get(language, self.tts_pipelines["en"])
        
        # Default voices per language
        default_voices = {
            "en": "af_bella",
            "fr": "ff_siwis",
        }
        voice = voice or default_voices.get(language, "af_bella")
        
        # Generate audio
        generator = pipeline(text, voice=voice, speed=speed)
        
        audio_chunks = []
        for _, _, audio in generator:
            audio_chunks.append(audio)
        
        full_audio = np.concatenate(audio_chunks)
        
        import io
        import soundfile as sf
        buffer = io.BytesIO()
        sf.write(buffer, full_audio, 24000, format='WAV')
        buffer.seek(0)
        
        return buffer.read()
    
    async def speech_to_speech(
        self,
        audio_bytes: bytes,
        language: str = "en",
        character: str = "kwe"
    ) -> bytes:
        """Complete speech-to-speech pipeline."""
        import requests
        import base64
        import tempfile
        
        # Save input audio
        with tempfile.NamedTemporaryFile(suffix='.wav', delete=False) as f:
            f.write(audio_bytes)
            audio_path = f.name
        
        # Call Chroma STS
        payload = {
            "model": "chroma",
            "messages": [
                {"role": "system", "content": self._get_character_prompt(character)},
                {"role": "user", "content": [{"type": "audio", "audio": audio_path}]}
            ],
            "max_tokens": 500,
            "return_audio": True
        }
        
        response = requests.post(self.chroma_url, json=payload)
        result = response.json()
        
        if result.get("audio"):
            return base64.b64decode(result["audio"])
        else:
            # Fallback to cascaded pipeline
            stt_result = await self.speech_to_text(audio_bytes, language)
            response_text = await self._generate_response(stt_result["text"], character)
            return await self.text_to_speech(response_text, language)
    
    def _get_character_prompt(self, character: str) -> str:
        """Get system prompt for a character."""
        prompts = {
            "kwe": "You are Kwe, a wise owl guide for Cameroonian children. Speak warmly and encouragingly.",
            "mbi": "You are Mbi, a curious monkey. Speak playfully and energetically.",
            "ngo": "You are Ngo, a brave girl from the Grassfields. Speak confidently and clearly.",
            "kong": "You are Kong, a resourceful boy from the coast. Speak adventurously and friendly."
        }
        return prompts.get(character, prompts["kwe"])
```

```typescript
// components/DIYLessonCard.tsx
interface DIYLesson {
  id: string;
  title: string;
  linkedLessonId: string;
  materials: {
    required: string[];
    optional: string[];
  };
  steps: DIYStep[];
  assessment: DIYAssessment;
  gamification: DIYGamification;
}

interface DIYStep {
  step: number;
  instruction: string;
  voiceGuide: string;
  audioUrl: string;
  duration: string;
}

export function DIYLessonCard({ lesson }: { lesson: DIYLesson }) {
  const [currentStep, setCurrentStep] = useState(0);
  const [completedSteps, setCompletedSteps] = useState<number[]>([]);
  
  return (
    <div className="diy-lesson-card">
      <div className="diy-header">
        <span className="diy-badge">🔨 DIY Practical</span>
        <h3>{lesson.title}</h3>
      </div>
      
      <div className="materials-section">
        <h4>Materials Needed</h4>
        <ul>
          {lesson.materials.required.map((item, i) => (
            <li key={i}>✓ {item}</li>
          ))}
        </ul>
      </div>
      
      <div className="steps-section">
        {lesson.steps.map((step, i) => (
          <div 
            key={i} 
            className={`diy-step ${completedSteps.includes(i) ? 'completed' : ''}`}
          >
            <div className="step-number">{step.step}</div>
            <div className="step-content">
              <p>{step.instruction}</p>
              <button 
                className="voice-guide-btn"
                onClick={() => playAudio(step.audioUrl)}
              >
                🔊 Listen
              </button>
              <span className="duration">{step.duration}</span>
            </div>
            <button 
              className="complete-btn"
              onClick={() => markComplete(i)}
            >
              {completedSteps.includes(i) ? '✓' : 'Done'}
            </button>
          </div>
        ))}
      </div>
      
      <div className="diy-reward">
        <p>Complete all steps to earn:</p>
        <span className="badge">{lesson.gamification.badge_name}</span>
        <span className="xp">+{lesson.gamification.xp_points} XP</span>
      </div>
    </div>
  );
}
```
