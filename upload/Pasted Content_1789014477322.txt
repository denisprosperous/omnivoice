## I. SYSTEM CONTEXT & OVERARCHING OBJECTIVE

### 1.1 Core Mission

You are to build a **Minimum Viable Product (MVP)** for an AI-powered educational platform that delivers a **complete, multimodal learning experience** across all educational levels from **Kindergarten through High School** (ISCED Levels 0-3). The platform must be **fully functional for the Cameroonian context** while maintaining **international relevance and standards**, exceeding the requirements set by the Ministry of Basic Education (MINEDUB) and aligning with globally recognized frameworks including **IB (PYP/MYP/DP)**, **Cambridge International (IGCSE/A-Levels)**, and the **Common European Framework of Reference for Languages (CEFR)**.

**Omnivoice Mandate:** The platform must deliver **complete voice functionality** including:
- **Speech-to-Text (STT):** Real-time transcription of learner speech in English, French, and Cameroonian national languages
- **Text-to-Speech (TTS):** Natural, culturally appropriate voice synthesis for all content
- **Speech-to-Speech (STS):** Real-time conversational AI that listens, understands, and responds verbally
- **Sound Design:** Immersive audio environments with authentic African musical elements

Every interaction must feel like a **conversation with a wise, playful elder** – warm, responsive, and deeply rooted in Cameroonian culture while preparing learners for global citizenship.

### 1.2 Foundational Documents & Standards

The MVP must be built upon and strictly aligned with:

**Cameroonian National Documents:**
1. The Cameroon Primary School Curriculum (Level I: Class 1 & Class 2) – 2018
2. The Regional Monthly Integrated Learning Plan for Primary Schools Level II (Class 3) – Littoral Region
3. The National Core Skills Framework
4. The 1998 Law to Lay Down Guidelines for Education

**International Frameworks (for KG-High School coverage):**
- **ISCED Levels 0-3:** Pre-primary (KG), Primary, Lower Secondary, Upper Secondary
- **IB Programmes:** PYP (Primary Years), MYP (Middle Years), DP (Diploma Programme)
- **Cambridge International:** Primary, Lower Secondary, IGCSE, AS & A Levels
- **CEFR Language Levels:** A1-C2 for language proficiency progression

### 1.3 Educational Philosophy

The platform must embody the **Competence-Based Approach (CBA)** with a focus on **Project-Based Learning (PBL)** , supported by **Integrated Theme Learning** and **Cooperative Learning** strategies. The core philosophy is that **"the learner should be responsible for his/her own learning"** and that **"focus is on learning and not on teaching."**

**Gamification Philosophy:** Learning is inherently playful. The platform will leverage intrinsic motivation through **curiosity, challenge, and mastery**, augmented by extrinsic rewards (points, badges, levels) that celebrate effort and progress. Every lesson is a **quest**; every correct answer is a **victory**.

**Voice-First Philosophy:** Language is the foundation of all learning. The platform treats voice as a **primary interface** – not an add-on. Learners speak, listen, and converse with AI characters who respond naturally, creating an immersive language environment from day one.

## III. OMNIVOICE: COMPLETE VOICE & AUDIO FRAMEWORK

### 3.1 Speech Technology Stack

The platform must integrate a **complete speech technology pipeline** supporting all modes of voice interaction:

#### 3.1.1 Speech-to-Text (STT) / Automatic Speech Recognition (ASR)

**Core Requirements:**
- Real-time transcription of learner speech in **English, French, and Cameroonian national languages**
- Support for **code-switching** (natural mixing of languages, common in Cameroon)
- Tone-aware recognition for Bantu languages

**African Language Models to Integrate:**

| Model | Architecture | Languages | Use Case |
|-------|--------------|-----------|----------|
| **Simba-S** | SeamlessM4T-v2 | 43 African languages | Best overall ASR performance |
| **Simba-W** | Whisper-v3-large | 43 African languages | High accuracy transcription |
| **Simba-X** | Wav2Vec2-XLS-R-2b | 43 African languages | Self-supervised learning |

**Cameroonian Language Datasets for Fine-Tuning:**

| Dataset | Language | Size | Features |
|---------|----------|------|----------|
| **Ewondo-ASR-Dataset** | Ewondo (ewo) | 1,781 recordings, 117 MB | GACL orthography with tone marking |
| **Bati-MultiDialectalASR-Dataset** | Bati (3 dialects) | 13,344 clips, 3.27 GB | Cross-dialectal, multilingual |

**Implementation Approach:**
```python
from transformers import pipeline

# Load Simba-S for multilingual African ASR
asr_pipeline = pipeline(
    "automatic-speech-recognition",
    model="UBC-NLP/Simba-S"
)

# For Cameroonian languages, fine-tune with local datasets
# Ewondo example with tone-aware transcription
result = asr_pipeline("learner_audio.wav")
# Output respects GACL orthography with tone diacritics
```

**Real-World Performance Considerations:**
- Current ASR performance for African languages ranges from 30-50% Word Error Rate (WER) for best-in-class models
- Africa-targeted models significantly outperform general-purpose models
- Plan for **human-in-the-loop verification** for critical assessments

### 5.5 Voice Pipeline Implementation

```python
# Complete voice pipeline for STS
class VoicePipeline:
    def __init__(self):
        self.asr = load_model("UBC-NLP/Simba-S")  # African ASR
        self.tts = EdgeTTS()  # Free TTS
        self.llm = OpenAIClient()  # Content generation
    
    async def speech_to_speech(self, audio_input: bytes) -> bytes:
        # Step 1: Speech to Text
        text = await self.asr.transcribe(audio_input)
        
        # Step 2: Generate Response
        response_text = await self.llm.generate(
            prompt=text,
            context=self.get_lesson_context()
        )
        
        # Step 3: Text to Speech
        audio_output = await self.tts.synthesize(
            text=response_text,
            voice="cameroonian_child_friendly"
        )
        
        return audio_output
    
    async def evaluate_pronunciation(
        self, 
        learner_audio: bytes, 
        target_text: str
    ) -> dict:
        # Transcribe learner speech
        transcription = await self.asr.transcribe(learner_audio)
        
        # Compare with target
        similarity = calculate_similarity(transcription, target_text)
        
        return {
            "transcription": transcription,
            "target": target_text,
            "accuracy": similarity,
            "feedback": generate_feedback(similarity)
        }
```
