### 2.3 Kom Language (Bikom) Specifications

**Language Details:**
- **Classification:** Benue-Congo → Narrow Grassfields → Central Ring
- **Location:** Boyo Division of the North West Region of Cameroon
- **Speakers:** Approximately 233,000 (2005 census)
- **Writing System:** Latin script with GACL modifications
- **Tones:** Three tones:
  - **High tone [˥]:** Not marked (unmarked)
  - **Falling tone [˥˩]:** Marked with circumflex (â)
  - **Low tone [˩]:** Marked with grave (à)

**Orthography (GACL-Compliant):**
- Uses the General Alphabet of Cameroonian Languages
- Special characters: ɛ, ɔ, ŋ, ɨ, ʉ
- Digraphs for complex sounds: ny, gh, sh, ch, j

### 2.4 Lamnso' (Lamso) Language Specifications

**Language Details:**
- **Classification:** Benue-Congo → Narrow Grassfields → Ring group → West ring
- **Location:** Nso Division of the Bamenda Province, North West Region
- **Speakers:** Approximately 125,000 (1987 census)
- **Dialects:** Unlike most African languages, Lamnso' has **no dialectal variations**
- **Writing System:** Latin script with GACL modifications

**Phonological Features:**
- **Vowels:** Six short vowel sounds: /i/, /e/, /a/, /o/, /ə/, /u/
- **Vowel Length:** Distinctive (e.g., *sú* "to wash" vs. *súü* "to harvest completely")
- **Consonants:** 53 consonants at phonetic level (including prenasalized and labialized)
- **Special Graphemes:**
  - [ɲ] = "ny"
  - [ʃ] = "sh"
  - [ɣ] = "gh"
  - [tʃ] = "c"
  - [dʒ] = "j"
  - [ʔ] = "?" or "♀"

| I am fine | Mǝ̀ yé | Response |
| What is your name? | Wù yé wǝ́? | Question form |

### 2.6 GACL Orthography Standards

All Grassfields language content must adhere to the **General Alphabet of Cameroonian Languages (GACL/AGLC)** established in 1979:

**Core Principles:**
1. **Tone Marking:** Tones must be written on syllable centers
   - If language has 2 lexical tones: mark 1
   - If language has 3 lexical tones: mark 2
   - Modulated tones: double vowels when possible

2. **Consonant Representation:**
   - Same sounds represented by same symbols across languages
   - Digraphs preferred over rare phonetic symbols
   - Examples: "ch" for [tʃ], "ng" for [ŋg]

3. **Special Characters:**
   - ɛ, ɔ, ŋ, ɨ, ʉ, ə
   - Prenasalized: mb, nd, ŋg, nj
   - Labialized: pʷ, fʷ, sʷ, kʷ
   - Palatalized: bʲ, dʲ, kʲ, sʲ

4. **Vowel Length:** Written as vowel geminate (doubled)

### 6.5 Voice Pipeline Implementation

```python
# Complete voice pipeline for STS with Grassfields language support
class VoicePipeline:
    def __init__(self):
        # Core models
        self.asr = load_model("UBC-NLP/Simba-S")  # African ASR
        self.tts = EdgeTTS()  # Free TTS
        self.llm = OpenAIClient()  # Content generation
        
        # Grassfields language models (fine-tuned)
        self.grassfields_models = {
            "bkm": load_model("custom/kom-asr-model"),  # Kom
            "lns": load_model("custom/lamnso-asr-model"),  # Lamnso'
            "bfd": load_model("custom/bafut-asr-model"),  # Bafut
            "oku": load_model("custom/oku-asr-model"),  # Oku
            "bbk": load_model("custom/babanki-asr-model"),  # Babanki
            "mgo": load_model("custom/mankon-asr-model"),  # Mankon
            "ngi": load_model("custom/ngie-asr-model"),  # Ngie
        }
    
    async def speech_to_speech(
        self, 
        audio_input: bytes,
        source_language: str = "auto",
        target_language: str = "en"
    ) -> bytes:
        # Step 1: Speech to Text
        if source_language in self.grassfields_models:
            text = await self.grassfields_models[source_language].transcribe(audio_input)
        else:
            text = await self.asr.transcribe(audio_input, language=source_language)
        
        # Step 2: Generate Response
        response_text = await self.llm.generate(
            prompt=text,
            context=self.get_lesson_context(),
            target_language=target_language
        )
        
        # Step 3: Text to Speech
        if target_language in self.grassfields_models:
            audio_output = await self.synthesize_grassfields(
                text=response_text,
                language=target_language
            )
        else:
            audio_output = await self.tts.synthesize(
                text=response_text,
                voice="cameroonian_child_friendly",
                language=target_language
            )
        
        return audio_output
    
    async def evaluate_pronunciation(
        self, 
        learner_audio: bytes, 
        target_text: str,
        language: str = "en"
    ) -> dict:
        # Transcribe learner speech
        if language in self.grassfields_models:
            transcription = await self.grassfields_models[language].transcribe(learner_audio)
        else:
            transcription = await self.asr.transcribe(learner_audio)
        
        # Compare with target (tone-aware for Grassfields)
        if language in ["bkm", "lns"]:  # Tonal languages
            similarity = calculate_tone_aware_similarity(transcription, target_text)
        else:
            similarity = calculate_similarity(transcription, target_text)
        
        return {
            "transcription": transcription,
            "target": target_text,
            "language": language,
            "accuracy": similarity,
            "tone_accuracy": calculate_tone_accuracy(transcription, target_text) if language in ["bkm", "lns"] else None,
            "feedback": generate_feedback(similarity, language)
        }
```
