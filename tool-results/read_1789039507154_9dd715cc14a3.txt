   147→### 2.3 Kom Language (Bikom) Specifications
   148→
   149→**Language Details:**
   150→- **Classification:** Benue-Congo → Narrow Grassfields → Central Ring
   151→- **Location:** Boyo Division of the North West Region of Cameroon
   152→- **Speakers:** Approximately 233,000 (2005 census)
   153→- **Writing System:** Latin script with GACL modifications
   154→- **Tones:** Three tones:
   155→  - **High tone [˥]:** Not marked (unmarked)
   156→  - **Falling tone [˥˩]:** Marked with circumflex (â)
   157→  - **Low tone [˩]:** Marked with grave (à)
   158→
   159→**Orthography (GACL-Compliant):**
   160→- Uses the General Alphabet of Cameroonian Languages
   161→- Special characters: ɛ, ɔ, ŋ, ɨ, ʉ
   162→- Digraphs for complex sounds: ny, gh, sh, ch, j

   179→### 2.4 Lamnso' (Lamso) Language Specifications
   180→
   181→**Language Details:**
   182→- **Classification:** Benue-Congo → Narrow Grassfields → Ring group → West ring
   183→- **Location:** Nso Division of the Bamenda Province, North West Region
   184→- **Speakers:** Approximately 125,000 (1987 census)
   185→- **Dialects:** Unlike most African languages, Lamnso' has **no dialectal variations**
   186→- **Writing System:** Latin script with GACL modifications
   187→
   188→**Phonological Features:**
   189→- **Vowels:** Six short vowel sounds: /i/, /e/, /a/, /o/, /ə/, /u/
   190→- **Vowel Length:** Distinctive (e.g., *sú* "to wash" vs. *súü* "to harvest completely")
   191→- **Consonants:** 53 consonants at phonetic level (including prenasalized and labialized)
   192→- **Special Graphemes:**
   193→  - [ɲ] = "ny"
   194→  - [ʃ] = "sh"
   195→  - [ɣ] = "gh"
   196→  - [tʃ] = "c"
   197→  - [dʒ] = "j"
   198→  - [ʔ] = "?" or "♀"

   225→### 2.6 GACL Orthography Standards
   226→
   227→All Grassfields language content must adhere to the **General Alphabet of Cameroonian Languages (GACL/AGLC)** established in 1979:
   228→
   229→**Core Principles:**
   230→1. **Tone Marking:** Tones must be written on syllable centers
   231→   - If language has 2 lexical tones: mark 1
   232→   - If language has 3 lexical tones: mark 2
   233→   - Modulated tones: double vowels when possible
   234→
   235→2. **Consonant Representation:**
   236→   - Same sounds represented by same symbols across languages
   237→   - Digraphs preferred over rare phonetic symbols
   238→   - Examples: "ch" for [tʃ], "ng" for [ŋg]
   239→
   240→3. **Special Characters:**
   241→   - ɛ, ɔ, ŋ, ɨ, ʉ, ə
   242→   - Prenasalized: mb, nd, ŋg, nj
   243→   - Labialized: pʷ, fʷ, sʷ, kʷ
   244→   - Palatalized: bʲ, dʲ, kʲ, sʲ
   245→
   246→4. **Vowel Length:** Written as vowel geminate (doubled)

   860→### 6.5 Voice Pipeline Implementation
   861→
   862→```python
   863→# Complete voice pipeline for STS with Grassfields language support
   864→class VoicePipeline:
   865→    def __init__(self):
   866→        # Core models
   867→        self.asr = load_model("UBC-NLP/Simba-S")  # African ASR
   868→        self.tts = EdgeTTS()  # Free TTS
   869→        self.llm = OpenAIClient()  # Content generation
   870→        
   871→        # Grassfields language models (fine-tuned)
   872→        self.grassfields_models = {
   873→            "bkm": load_model("custom/kom-asr-model"),  # Kom
   874→            "lns": load_model("custom/lamnso-asr-model"),  # Lamnso'
   875→            "bfd": load_model("custom/bafut-asr-model"),  # Bafut
   876→            "oku": load_model("custom/oku-asr-model"),  # Oku
   877→            "bbk": load_model("custom/babanki-asr-model"),  # Babanki
   878→            "mgo": load_model("custom/mankon-asr-model"),  # Mankon
   879→            "ngi": load_model("custom/ngie-asr-model"),  # Ngie
   880→        }
   881→    
   882→    async def speech_to_speech(
   883→        self, 
   884→        audio_input: bytes,
   885→        source_language: str = "auto",
   886→        target_language: str = "en"
   887→    ) -> bytes:
   888→        # Step 1: Speech to Text
   889→        if source_language in self.grassfields_models:
   890→            text = await self.grassfields_models[source_language].transcribe(audio_input)
   891→        else:
   892→            text = await self.asr.transcribe(audio_input, language=source_language)
   893→        
   894→        # Step 2: Generate Response
   895→        response_text = await self.llm.generate(
   896→            prompt=text,
   897→            context=self.get_lesson_context(),
   898→            target_language=target_language
   899→        )
   900→        
   901→        # Step 3: Text to Speech
   902→        if target_language in self.grassfields_models:
   903→            audio_output = await self.synthesize_grassfields(
   904→                text=response_text,
   905→                language=target_language
   906→            )
   907→        else:
   908→            audio_output = await self.tts.synthesize(
   909→                text=response_text,
   910→                voice="cameroonian_child_friendly",
   911→                language=target_language
   912→            )
   913→        
   914→        return audio_output
   915→    
   916→    async def evaluate_pronunciation(
   917→        self, 
   918→        learner_audio: bytes, 
   919→        target_text: str,
   920→        language: str = "en"
   921→    ) -> dict:
   922→        # Transcribe learner speech
   923→        if language in self.grassfields_models:
   924→            transcription = await self.grassfields_models[language].transcribe(learner_audio)
   925→        else:
   926→            transcription = await self.asr.transcribe(learner_audio)
   927→        
   928→        # Compare with target (tone-aware for Grassfields)
   929→        if language in ["bkm", "lns"]:  # Tonal languages
   930→            similarity = calculate_tone_aware_similarity(transcription, target_text)
   931→        else:
   932→            similarity = calculate_similarity(transcription, target_text)
   933→        
   934→        return {
   935→            "transcription": transcription,
   936→            "target": target_text,
   937→            "language": language,
   938→            "accuracy": similarity,
   939→            "tone_accuracy": calculate_tone_accuracy(transcription, target_text) if language in ["bkm", "lns"] else None,
   940→            "feedback": generate_feedback(similarity, language)
