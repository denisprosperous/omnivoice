    42→
    43→**Why Kokoro?**
    44→
    45→Kokoro is an open-source TTS model that transforms text into natural-sounding speech with remarkable efficiency. Despite its compact size of 82 million parameters, it delivers high-quality voice synthesis comparable to models ten times larger.
    46→
    47→**Key Features:**
    48→- **54 voices** across multiple languages (English, French, Japanese, Chinese, Hindi)
    49→- **Near real-time generation** on modern hardware
    50→- **Natural prosody** that sounds human, not robotic
    51→- **Voice cloning** via reference audio
    52→
    53→**Available Voices:**
    54→
    55→| Category | Voice IDs | Use Case |
    56→|----------|-----------|----------|
    57→| **American Female** | `af_bella`, `af_sarah`, `af_sky`, `af_nicole` | Child-friendly characters |
    58→| **American Male** | `am_adam`, `am_michael`, `am_liam`, `am_eric` | Teacher/guide voices |
    59→| **British Female** | `bf_emma`, `bf_alice`, `bf_isabella` | Formal narration |
    60→| **British Male** | `bm_george`, `bm_lewis`, `bm_daniel` | Authority figures |
    61→| **French** | `ff_siwis` | Français content |

    63→**Installation:**

    79→

    81→pipeline = KPipeline(lang_code='a')  # 'a' for American English

    92→
    93→**Integration with Platform:**
    94→```python
    95→# server/services/kokoro_tts.py
    96→from kokoro import KPipeline
    97→import io
    98→import soundfile as sf
    99→
   100→class KokoroTTSService:
   101→    def __init__(self):
   102→        self.pipelines = {
   103→            'en': KPipeline(lang_code='a'),  # American English
   104→            'fr': KPipeline(lang_code='f'),  # French
   105→        }
   106→        self.default_voices = {
   107→            'en': 'af_bella',
   108→            'fr': 'ff_siwis',
   109→        }
   110→    
   111→    async def synthesize(
   112→        self,
   113→        text: str,
   114→        language: str = 'en',
   115→        voice: str = None,
   116→        speed: float = 1.0
   117→    ) -> bytes:
   118→        """Generate natural-sounding speech."""
   119→        pipeline = self.pipelines.get(language, self.pipelines['en'])
   120→        voice = voice or self.default_voices.get(language, 'af_bella')
   121→        
   122→        # Generate audio
   123→        generator = pipeline(text, voice=voice, speed=speed)
   124→        
   125→        # Collect audio chunks
   126→        audio_chunks = []
   127→        for _, _, audio in generator:
   128→            audio_chunks.append(audio)
   129→        
   130→        # Concatenate and convert to bytes
   131→        import numpy as np
   132→        full_audio = np.concatenate(audio_chunks)
   133→        
   134→        buffer = io.BytesIO()
   135→        sf.write(buffer, full_audio, 24000, format='WAV')
   136→        buffer.seek(0)
   137→        
   138→        return buffer.read()
   139→```

   192→# server/services/faster_whisper_stt.py
   193→from faster_whisper import WhisperModel
   194→
   195→class FasterWhisperSTTService:
   196→    def __init__(self):
   197→        # Load models for different languages
   198→        self.models = {
   199→            'base': WhisperModel("base", device="cuda", compute_type="float16"),
   200→            'small': WhisperModel("small", device="cuda", compute_type="float16"),
   201→        }
   202→    
   203→    async def transcribe(
   204→        self,
   205→        audio_bytes: bytes,
   206→        language: str = None,
   207→        model_size: str = 'base'
   208→    ) -> dict:
   209→        """Transcribe audio to text with language detection."""
   210→        # Save to temporary file
   211→        import tempfile
   212→        with tempfile.NamedTemporaryFile(suffix='.wav', delete=False) as f:
   213→            f.write(audio_bytes)
   214→            audio_path = f.name
   215→        
   216→        # Transcribe
   217→        model = self.models.get(model_size, self.models['base'])
   218→        segments, info = model.transcribe(
   219→            audio_path,
   220→            language=language,  # None for auto-detect
   221→            beam_size=5,
   222→            word_timestamps=True
   223→        )
   224→        
   225→        # Collect results
   226→        transcription = " ".join([segment.text for segment in segments])
   227→        
   228→        return {
   229→            "text": transcription.strip(),
   230→            "language": info.language,
   231→            "language_probability": info.language_probability,
   232→            "duration": info.duration
   233→        }
   234→```

   305→#### Option B: MOSS-Speech (True Speech-to-Speech Without Text Guidance)
   306→
   307→MOSS-Speech introduces true end-to-end speech interaction. Unlike cascaded pipelines or text-guided models, it directly generates speech without first producing text. This overcomes the limitation of generated speech being constrained by a text bottleneck, enabling more natural and efficient speech-to-speech dialogue.
   308→
   309→**Key Features:**
   310→- **True Speech-to-Speech Modeling:** No text guidance required
   311→- **Layer-Splitting Architecture:** Integrates modality-specific layers on top of pretrained text LLM backbones
   312→- **Frozen Pre-Training Strategy:** Preserves LLM reasoning while enhancing speech understanding and generation
   313→- **Expressive & Efficient:** Maintains paralinguistic cues often lost in cascaded pipelines, such as tone, emotion, and prosody
   314→
   315→**Installation:**
   316→```bash
   317→# Clone repository
   318→git clone https://github.com/OpenMOSS/MOSS-Speech
   319→cd MOSS-Speech
   320→
   321→# Install dependencies
   322→pip install -r requirements.txt
   323→git submodule update --init --recursive
   324→
   325→# Launch web demo
   326→python3 gradio_demo.py
   327→```
   328→
   329→**Python API:**
   330→```python
   331→import os
   332→from dataclasses import astuple
   333→import torch
   334→import torchaudio
   335→from transformers import AutoModel, AutoProcessor, GenerationConfig
   336→
   337→model_path = "fnlp/MOSS-Speech"
   338→codec_path = "fnlp/MOSS-Speech-Codec"
   339→
   340→processor = AutoProcessor.from_pretrained(
   341→    model_path, 
   342→    codec_path=codec_path, 
   343→    device="cuda", 
   344→    trust_remote_code=True
   345→)
   346→
   347→model = AutoModel.from_pretrained(
   348→    model_path, 
   349→    trust_remote_code=True, 
   350→    device_map="cuda"
   351→).eval()
   352→
   353→messages = [
   354→    {"role": "system", "content": "You are a helpful voice assistant for Cameroonian children."},
   355→    {"role": "user", "content": "À bwɛ̀! Nà wù dà?"}
   356→]
   357→
   358→encoded_inputs = processor(messages, "audio")
   359→
   360→with torch.inference_mode():
   361→    token_ids = model.generate(
   362→        input_ids=encoded_inputs["input_ids"].to("cuda"),
   363→        attention_mask=encoded_inputs["attention_mask"].to("cuda"),
   364→    )
   365→
   366→results = processor.decode(token_ids, "audio")
   367→audio, text, sample_rate = astuple(results[0])
   368→
   369→# Save audio
   370→torchaudio.save("response.wav", audio, sample_rate)
   371→```

   483→### 2.2 Voice Service Registry
   484→

   486→# server/services/voice_registry.py
   487→from enum import Enum
   488→from dataclasses import dataclass
   489→from typing import Optional
   490→
   491→class TTSBackend(Enum):
   492→    KOKORO = "kokoro"

   532→            tts_backend=TTSBackend.KOKORO,

   534→            sts_backend=STSBackend.CHROMA,
   535→            tts_voice="ff_siwis",
   536→            tts_speed=0.95,
   537→            stt_model="base",
   538→            stt_language="fr"
   539→        ),
   540→        "bkm": VoiceConfig(  # Kom
   541→            tts_backend=TTSBackend.KOKORO,  # With voice cloning

   568→    
   569→    def get_config(self, language: str) -> VoiceConfig:

   574→### 2.3 Unified Voice Service

   577→# server/services/unified_voice.py
   578→from typing import Optional

   580→
   581→class UnifiedVoiceService:
   582→    """Complete voice pipeline: STT → LLM → TTS with STS option."""
   583→    
   584→    def __init__(self):
   585→        # Initialize STT
   586→        from faster_whisper import WhisperModel
   587→        self.stt_models = {
   588→            "base": WhisperModel("base", device="cuda", compute_type="float16"),
   589→            "small": WhisperModel("small", device="cuda", compute_type="float16"),
   590→        }
   591→        
   592→        # Initialize TTS
   593→        from kokoro import KPipeline
   594→        self.tts_pipelines = {
   595→            "en": KPipeline(lang_code='a'),
   596→            "fr": KPipeline(lang_code='f'),
   597→        }
   598→        
   599→        # Initialize STS (Chroma)
   600→        self.chroma_url = "http://localhost:8000/v1/chat/completions"
   601→    
   602→    async def speech_to_text(
   603→        self,
   604→        audio_bytes: bytes,
   605→        language: Optional[str] = None,
   606→        model_size: str = "base"
   607→    ) -> dict:
   608→        """Convert speech to text."""
   609→        import tempfile
   610→        with tempfile.NamedTemporaryFile(suffix='.wav', delete=False) as f:
   611→            f.write(audio_bytes)
   612→            audio_path = f.name
   613→        
   614→        model = self.stt_models.get(model_size, self.stt_models["base"])
   615→        segments, info = model.transcribe(
   616→            audio_path,
   617→            language=language,
   618→            beam_size=5,
   619→            word_timestamps=True
   620→        )
   621→        
   622→        transcription = " ".join([seg.text for seg in segments])
   623→        
   624→        return {
   625→            "text": transcription.strip(),
   626→            "language": info.language,
   627→            "confidence": info.language_probability,
   628→        }
   629→    
   630→    async def text_to_speech(
   631→        self,
   632→        text: str,
   633→        language: str = "en",
   634→        voice: Optional[str] = None,
   635→        speed: float = 1.0
   636→    ) -> bytes:
   637→        """Convert text to natural speech."""
   638→        pipeline = self.tts_pipelines.get(language, self.tts_pipelines["en"])
   639→        
   640→        # Default voices per language
   641→        default_voices = {
   642→            "en": "af_bella",
   643→            "fr": "ff_siwis",
   644→        }
   645→        voice = voice or default_voices.get(language, "af_bella")
   646→        
   647→        # Generate audio
   648→        generator = pipeline(text, voice=voice, speed=speed)
   649→        
   650→        audio_chunks = []
   651→        for _, _, audio in generator:
   652→            audio_chunks.append(audio)
   653→        
   654→        full_audio = np.concatenate(audio_chunks)
   655→        
   656→        import io
   657→        import soundfile as sf
   658→        buffer = io.BytesIO()
   659→        sf.write(buffer, full_audio, 24000, format='WAV')
   660→        buffer.seek(0)
   661→        
   662→        return buffer.read()
   663→    
   664→    async def speech_to_speech(
   665→        self,
   666→        audio_bytes: bytes,
   667→        language: str = "en",
   668→        character: str = "kwe"
   669→    ) -> bytes:
   670→        """Complete speech-to-speech pipeline."""
   671→        import requests
   672→        import base64
   673→        import tempfile
   674→        
   675→        # Save input audio
   676→        with tempfile.NamedTemporaryFile(suffix='.wav', delete=False) as f:
   677→            f.write(audio_bytes)
   678→            audio_path = f.name
   679→        
   680→        # Call Chroma STS
   681→        payload = {
   682→            "model": "chroma",
   683→            "messages": [
   684→                {"role": "system", "content": self._get_character_prompt(character)},
   685→                {"role": "user", "content": [{"type": "audio", "audio": audio_path}]}
   686→            ],
   687→            "max_tokens": 500,
   688→            "return_audio": True
   689→        }
   690→        
   691→        response = requests.post(self.chroma_url, json=payload)
   692→        result = response.json()
   693→        
   694→        if result.get("audio"):
   695→            return base64.b64decode(result["audio"])
   696→        else:
   697→            # Fallback to cascaded pipeline
   698→            stt_result = await self.speech_to_text(audio_bytes, language)
   699→            response_text = await self._generate_response(stt_result["text"], character)
   700→            return await self.text_to_speech(response_text, language)
   701→    
   702→    def _get_character_prompt(self, character: str) -> str:
   703→        """Get system prompt for a character."""
   704→        prompts = {
   705→            "kwe": "You are Kwe, a wise owl guide for Cameroonian children. Speak warmly and encouragingly.",
   706→            "mbi": "You are Mbi, a curious monkey. Speak playfully and energetically.",
   707→            "ngo": "You are Ngo, a brave girl from the Grassfields. Speak confidently and clearly.",
   708→            "kong": "You are Kong, a resourceful boy from the coast. Speak adventurously and friendly."
   709→        }
   710→        return prompts.get(character, prompts["kwe"])
   711→```
